# Boum Arena

Jeu de bombes multijoueur (IA, même appareil ou en ligne).

Jouer : https://grem60000-sys.github.io/boum-arena/

En ligne : l hôte touche « Créer », les autres « Rejoindre » avec le code. Mise en relation via Supabase Realtime, puis connexion directe entre appareils (WebRTC), avec relais Supabase si besoin.
